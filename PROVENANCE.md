# Where this came from

Written from scratch for this repository, on a laptop, against a docker compose stack on that laptop.

Nothing here is copied from an employer's codebase. There is no proprietary code, no customer data, no
internal hostname and no credential in this repository, and the docker compose stack listens on localhost
only.

The numbers in `README.md` were measured by running the commands next to them; the three findings were each
a failure seen on the running stack before they were written down. Where something is not verified it says
so — the CI job that brings the stack up has not been run on a GitHub runner yet.
